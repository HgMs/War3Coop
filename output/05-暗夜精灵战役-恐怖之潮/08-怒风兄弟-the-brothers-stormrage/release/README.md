## 重要：槽位规则

- 玩家 1“尤迪安的娜迦”：必须由真人占用，控制尤迪安、娜迦基地与原版部队，并负责选择普通或困难；30 秒无输入时采用普通。
- 玩家 2“玛尔法里奥的部队”由真人占用：控制玛尔法里奥、暗夜精灵基地与原版部队；与玩家 1结盟、共享视野并共同结算，默认不共享单位控制或资源；与中立敌对单位双向敌对。
- 玩家 2设为电脑、关闭、空槽或未加入：目标行为是开局一次性恢复 Neutral 所有权、原版玩家 1共享控制和原版外交；不启动 P3 AI、不转移资产或资源。上述四类大厅状态没有逐项实机日志，属于本版已接受风险。
- “哨兵”槽：必须保持地图默认电脑，由泰兰德和 `N08X03.ai` 继续控制；不得开放为真人。
- 开局后控制模式固定；真人中途退出或断线采用游戏引擎默认行为，不提供 AI 接管、资产转移或资源重置。

## 相对原版的主要改动

- 将原版 Neutral 的玛尔法里奥阵营开放为可选第二真人槽，并按初始化时的 controller 与 slot state 一次性分类。
- 双真人时双方独立控制各自基地、经济、科技和人口，共享视野、共同胜利，并保留联盟菜单及资源交易。
- 保留泰兰德电脑阵营、原版 `N08X03.ai`、初始资源和低资源补贴；不为玛尔法里奥阵营新增 AI或补贴。
- 增加玩家 1普通/困难选择，选择完成前不运行原版初始化触发器、AI、任务或过场。
- 尤迪安、玛尔法里奥和泰兰德使用官方缓存缺失时的固定 10级技能配置；移除战役缓存读取、保存、关卡解锁和下一关跳转。
- 保留尤迪安的官方 `gldo`；在玛维第一物品点生成一个 `sora`，不创建玛维、马格罗斯或马格罗斯物品。
- 将 `Udea/Udre/Ulic` 的地图对象人口设为 0，使验收范围内全部可达战役英雄有效人口为 0。
- 水坝发现、任务揭示、临时视野、快速镜头、过场和跳过扩展到两名活跃真人；双方分别恢复选择和本地镜头。
- 保留原版胜利和三条失败门槛；双真人同步结算，单人回退只结算玩家 1。
