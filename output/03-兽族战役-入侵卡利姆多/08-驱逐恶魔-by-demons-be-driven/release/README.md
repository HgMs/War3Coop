## 重要：第二阵营槽位

单人游玩时，请勿关闭第二阵营“人类探险队”的玩家槽，必须将其设置为“电脑”，否则吉安娜及人族基地不会加载原版战役 AI。双人合作时由第二名真人玩家占用该槽。

- 玩家 1：红色兽人部落，控制萨尔、凯恩、完整兽人基地和原版资产。
- 玩家 2真人：浅蓝色人类探险队，控制吉安娜、完整人族基地和原版资产；人族 AI及其作弊经济停用。
- 玩家 2电脑：运行原版吉安娜 Campaign AI、经济补贴、进攻节奏和官方外交。
- 玩家 2关闭/空槽：不支持。运行期无法把 `PLAYER_SLOT_STATE_EMPTY` 恢复为正在游戏的电脑玩家。

## 相对原版的主要改动

- 将原版电脑控制的人类探险队开放为可选真人合作阵营，玩家 1仍保留完整兽人阵营。
- 增加普通/困难开局选择，30秒未选择时采用普通难度。
- 双真人同步任务结算、主要过场、跳过、镜头反馈和瀑布视野。
- 联盟菜单和资源交易可用，不自动共享单位控制；剧情外交恢复不会清除玩家手动授权。
- 真人玩家 2使用1000金、400木的合作经济；电脑玩家 2保留原版10000金、10000木及周期补贴。
- 固定萨尔、凯恩和吉安娜的等级、技能与装备，移除战役缓存和自动进入下一关的依赖。
- 保持全部可达战役英雄0人口占用；禁用资料片额外开放的暗影猎手与血魔法师。
- 锁定五个敌对电脑槽的既定种族，保留原版地形、任务、敌军、波次和剧情。
