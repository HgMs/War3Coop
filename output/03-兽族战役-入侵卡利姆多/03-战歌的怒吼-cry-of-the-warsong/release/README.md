- 兼容目标：Warcraft III 1.24e-1.27b；1.31为尽力兼容

## 重要：战歌槽位

单人游玩时必须把玩家 2“战歌部落”设置为电脑，不能关闭或留空。双人合作时由第二名真人占用该槽。

- 玩家 1：红色兽人部落，控制萨尔及原版部队。
- 玩家 2真人：控制格罗姆、完整战歌基地和军队；战歌 AI、AI补贴、AI复活、周期命令及自动反目停用。
- 玩家 2电脑：保留原版 `o03_grom.ai`、经济补贴、阶段命令、AI复活和战歌反目。
- 玩家 2关闭、空槽或未加入：不支持，不会被当作正在游戏的电脑槽。

## 相对原版的主要改动

- 将原版电脑控制的完整战歌阵营开放为可选真人合作阵营，并按开局控制模式一次性分流。
- 真人模式下双方结盟、共享视野并共同结算；默认不共享单位控制，保留联盟菜单和资源交易。
- 真人战歌不执行原版自动反目；电脑战歌完整保留“萨尔攻击战歌后格罗姆反目”的官方机制。
- 真人战歌与野怪双向敌对；电脑战歌保留原版外交。
- 真人战歌精确镜像萨尔阵营的科技与升级限制；萨尔阵营同时关闭目标客户端额外开放的 TFT兽族内容。
- 萨尔固定3级并携带 `rin1/rst1/penr/hlst/whwd/shea`；治疗守卫使用1.24e原生3次，医疗卷轴使用原生1次。
- 格罗姆固定4级并保留官方兜底技能，不携带物品；全部可达战役英雄保持0人口占用。
- 增加普通/困难开局选择，30秒未选择时采用普通难度。
- 移除战役缓存、关卡解锁和下一关跳转，保留原版任务、地形、敌军、过场及 P0所有权门槛。
