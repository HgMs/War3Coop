# 诸神黄昏：2-3人合作版 v1.0.0

- 发布日期：2026-09-11
- 地图：[NightElf07-Coop-v1.0.0.w3x](NightElf07-Coop-v1.0.0.w3x)
- 地图 SHA-256：`E20885A118A3FDA99CCBFF059557F63DF8F27449D46277354E0E52D1E183017C`
- 地图大小：309247 字节
- 检查报告：[NightElf07-Coop-v1.0.0.inspection.json](NightElf07-Coop-v1.0.0.inspection.json)
- 合作人数：2-3名真人；玩家 2暗夜精灵必须为真人
- 兼容目标：Warcraft III 1.24e-1.27b；1.31为尽力兼容

## 大厅槽位

- 玩家 1：兽族部落，由真人或电脑占用；不得关闭或留空。
- 玩家 2：暗夜精灵哨兵，必须为真人，并在进图后选择普通或困难。
- 玩家 10：人类探险队，由真人或电脑占用；不得关闭或留空。
- 仅一个友方槽由真人占用时是2人合作；兽族和人类均为真人时是3人合作。未由真人占用的友方槽必须在大厅明确设为电脑。

## 主要改动

- 将原版电脑控制的兽族和人类完整阵营分别开放为可选真人槽；电脑模式保留对应官方 Campaign AI、命令和周期补给。
- 真人兽族/人类与暗夜精灵统一为1000金、800木开局，不获得AI周期补给；电脑槽保留原版6500/6500与补给。
- 任务、45分钟倒计时、主要过场、跳过和胜负结算扩展到所有活跃真人；两次友军基地失守仍只推进原版阶段。
- 三阵营保持独立资源和人口，不自动共享单位控制；保留联盟菜单与资源交易。
- 以RoC官方原图在TFT客户端下运行的科技闭包为基线：兽族保留白牛体系与燃烧之油，人类保留碎片攻击与神秘之塔；移除龙鹰体系、三族TFT新商店和全部新增祭坛英雄。
- 独立地图不读写战役缓存、不解锁电影、不加载下一关。四名可玩英雄使用负责人确认的固定物品；泰兰德与玛法里奥均为7级、各分配6点技能并剩余1点。
- 开局可选普通或困难；30秒未选择时自动采用普通。难度只使用官方战役分支，不按合作人数另外缩放。

## 验证结论

- 发布地图与负责人批准的第6阶段候选逐字节一致，SHA-256相同。
- 从受控官方底图重复构建得到相同哈希；1.24e `common.j`/`Blizzard.j` 与 `pjass` 语义编译通过。
- 自动化验证了三个真人槽、两个友方AI分支、资源与补给、科技闭包、英雄技能/物品、过场跳过、共同结算和跨关副作用清理。
- 发布封包检查：地图格式18、编辑器 `v4448`、JASS、84x148、173个放置单位、4078个装饰物。
- 项目负责人于2026-09-11明确要求发布并提交 `v1.0.0`，第6阶段验收门禁已解除。

未提供按客户端版本和场景拆分的完整实机结果。1.24e/1.27b完整矩阵、1.31尽力兼容、2人两种阵营组合、3人完整通关、存读档和长局同步均不记为已通过；负责人接受为 `v1.0.0` 已知风险。

## 已知问题

- 玩家 1或玩家 10关闭、空槽或未加入时不受支持；未由真人占用时必须明确设置为电脑。
- 困难难度的一次实机中观察到剩余约20分钟后亡灵英雄未再参与进攻。静态对照未发现合作化改动触及敌方AI；官方 `n07_rainbow.ai` 的英雄派遣逻辑存在英雄尚未就绪时丢失该次派遣的可能，但尚未取得完整可重复证据。`v1.0.0` 保持官方敌方AI不变。
- 地图内部名称仍含“开发版”；为保持已验收 SHA，本次发布不再修改二进制。
- 检查器对可选 `war3map.imp` 报告版本枚举警告；其余地图结构、脚本和放置对象正常解析。
- 真人中途退出或断线采用引擎默认行为，不提供AI接管、资产转移或资源重置。
