# 游戏本体目录

本目录用于存放相互隔离的《魔兽争霸 III：冰封王座》经典客户端和对应 World Editor。仓库不提供游戏本体；开发者克隆项目后，需要自行合法取得所需版本并放入本目录。除本说明文件外，`game/` 下的所有内容均被 Git 忽略。

```text
game/
  Warcraft3-1.20.7z
  Warcraft III - 1.31.7z
  Warcraft3-1.20/
  Warcraft III - 1.31/
```

当前开发与验证只需要 `1.20e` 和 `1.31` 两个版本。压缩包名称和解压目录可以按本地习惯调整，但相关工具配置应指向实际路径；不要将压缩包、安装目录或其中的任何游戏资源强制加入 Git。

每个版本目录应保持完整、可离线启动，并包含该版本的游戏客户端和 World Editor。禁止从会自动升级的共享安装目录直接运行测试。实际小版本、语言和文件完整性应在解压后记录。
