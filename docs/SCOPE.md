# 范围与验收标准

## 核心范围

本项目的关卡说明覆盖《魔兽争霸 III：混乱之治》和《魔兽争霸 III：冰封王座》的经典战役。多人地图分批实施；未列入当前批次的关卡只保留说明，不预建制作目录。

第一批制作 9 关：战歌的怒吼、驱逐恶魔、诸神黄昏、权衡利弊、达拉然废墟、怒风兄弟、外域之王、阿尔萨斯国王、洛丹伦的新势力。

“合作版”默认指两个或更多真人玩家共同完成原战役关卡。具体人数可以按关卡设计确定，不要求所有关卡支持相同人数，但必须在地图说明中写明。

## 原版还原原则

除多人化和《冰封王座》适配所必需的改动外，默认保留：

- 地形、装饰物、镜头和过场演出；
- 主线与可选任务、触发顺序和对白；
- 敌方布局、进攻波次和关卡节奏；
- 英雄成长、物品和跨关状态；
- 原版难度意图。

允许调整的内容包括玩家槽位、出生位置、控制权、共享机制、资源供给、人口上限、任务同步、断线/离开处理，以及因多人规模导致的必要难度校正。所有显著偏离原版的调整都应记录原因。

## 《冰封王座》适配

所有关卡，包括源自《混乱之治》的关卡，均以《冰封王座》的规则与数据体系作为成品标准。适配不只是转换地图格式或调整维修费，而应覆盖：

- 游戏机制：经济、资源采集、人口、维修费、建造、训练、升级、英雄与经验等全局规则；
- 战斗体系：攻击类型、护甲类型、攻击对不同护甲的伤害关系，以及相关技能的伤害判定；
- 对象数据：单位、英雄、建筑、技能、科技、升级和物品的类型与数值字段；
- 关卡脚本：检查依赖《混乱之治》旧规则或旧对象数据的触发器、任务条件与数值假设；
- 表现与资源：使用《冰封王座》的地图类型和可用资源，并检查模型、图标、声音与文字等引用。

典型差异包括但不限于：

- 标准维修费区间为 0-50 人口无维修费（保留 100% 金矿收入）、51-80 人口低维修费（保留 70%）、81 人口起高维修费（保留 40%）；
- 《冰封王座》重构了攻击与护甲的克制关系；魔法攻击并非新增类型，但其对重型护甲的伤害由《混乱之治》1.06 的 100% 调整为 200%；
- 单位的攻击或护甲类型可能发生变化，例如人族步兵由《混乱之治》的中型护甲调整为《冰封王座》的重型护甲；
- 穿刺攻击对重型护甲的伤害由《混乱之治》1.06 的 150% 调整为《冰封王座》的 100%，因此重型护甲的主要克制来源转为魔法攻击。

以上只是便于识别的示例，不构成封闭清单。制作时应以经典《冰封王座》数据为基准逐项核对，不得仅确认维修费或地图格式后便视为适配完成。也不得机械套用《重制版》或当前对战平衡数据；若关卡为叙事或脚本需要保留特制数值，应在关卡说明中记录理由。

多人共享人口时按共享总人口计算；玩家各自拥有经济与人口时按各玩家分别计算。具体模式必须在关卡说明中明确。

维修费区间以 Blizzard 的[经典游戏指南](https://classic.battle.net/war3/basics/upkeep.shtml)为规则依据。

攻击与护甲的伤害关系以 Blizzard 的[经典攻击与护甲类型表](https://classic.battle.net/war3/basics/armorandweapontypes.shtml)为规则依据。

## 单关完成定义

一张地图只有同时满足以下条件才可标记为完成：

1. 所有目标玩家都能进入、正常出生并参与关卡。
2. 主线任务、可选任务、过场、胜利和失败流程均能同步完成。
3. 不会因任一玩家跳过过场、离开游戏或单位死亡而永久卡关。
4. 关卡在目标版本矩阵中通过从开局到结算的完整联机回归。
5. 与原版的差异、已知问题、来源和授权信息已记录。

## 非目标

- 不重制画面或改写剧情。
- 不默认加入新英雄、新兵种、新任务或大规模地形重做。
- 不依赖 1.28+ 才提供的玩家槽位、原生函数、Lua、Frame API 或地图文件结构。
- 不以 Reforged/2.0+ 专属素材或功能作为实现基础。
