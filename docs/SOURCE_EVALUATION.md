# 底图来源评估流程

社区地图站点、检索方法、首批候选及网页初筛结论见[社区合作战役来源与候选](COMMUNITY_SOURCES.md)。本文件继续作为单关采用或拒绝的正式评分与来源记录规范。

## 决策顺序

每个战役或关卡按以下顺序寻找底图：

1. 搜索已有的经典版多人合作战役或单关作品。
2. 核对作者、原始发布页、更新时间、目标版本、是否可编辑以及许可/改编授权。
3. 对比原版关卡，评估地形、剧情、任务、波次、单位数据和演出的偏离程度。
4. 若只需少量修改即可满足本项目标准，则申请授权或按许可引入并保留来源记录。
5. 若没有合适作品，或还原成本不低于重新制作，则从合法拥有的原版游戏数据中提取官方关卡作为工作底图。

不得仅凭下载链接或转载包引入作品。来源不明、地图被保护且无法审计、许可不允许修改/再分发，任一情况都足以否决候选。

## 候选评分

每个候选按 0-3 分记录：

| 维度 | 0 分 | 3 分 |
| --- | --- | --- |
| 原版还原度 | 大幅重做 | 仅有合作必需改动 |
| 经典兼容性 | 依赖 Reforged/后期 API | 已验证 1.20-1.27 |
| 可维护性 | 受保护、脚本不可读 | 可编辑、结构清晰 |
| 完整性 | 核心流程缺失/易卡关 | 主支线及演出完整 |
| 授权清晰度 | 来源或许可不明 | 作者明确允许修改和分发 |
| 改造成本 | 接近重做 | 少量可审计修改 |

授权清晰度为 0 时不进入仓库，不以总分抵消。

## 初步调研结论

- Hive Workshop 长期存在 TheSpoon 等作者制作的 [2 Player Campaign](https://www.hiveworkshop.com/threads/download-the-campaign.175670/)，形式是可在局域网中游玩的独立 `.w3x` 地图，值得作为首批候选继续核验。
- 社区反馈显示，不少现有版本已经转向 1.29+ 或 Reforged，不能仅凭“经典画面”判断其兼容性，必须用实际地图和目标客户端测试。
- 2026 年发布的 [Campaign Splitter](https://www.hiveworkshop.com/threads/%F0%9F%93%A2spotlight-campaign-splitter-co-op-custom-campaigns.372456/) 已能自动拆分 `.w3n` 并加入 Archon Mode，但其合作功能明确依赖 Reforged，不能满足本项目 1.20-1.27 的硬性要求；其“战役数据合并”思路可以作为工具调研参考。
