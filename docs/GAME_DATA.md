# 游戏数据需求

状态：游戏数据不随仓库提供。开发者克隆项目后，需要自行合法取得所需版本并放入 `game/`；该目录中的本体、压缩包和提取数据均被 Git 忽略。

## 是否需要

需要。原因有两类：

1. 如果现有社区作品不满足要求，需要从合法拥有的经典版游戏中提取原版战役地图、对象数据、本地化文本、语音和依赖资源进行制作与对照。
2. 无论底图来自哪里，都必须在真实客户端中完成多人兼容回归；只用编辑器或静态工具无法证明 1.20-1.27 可运行。

只应使用合法取得且与有效游戏许可对应的数据。游戏安装目录和提取出的原始数据均属于本地开发依赖，不提交到 Git。

## 当前保留版本

项目当前只在 `game/` 中保留两个相互隔离的《冰封王座》环境：

| 版本 | 需要的内容 | 用途 |
| --- | --- | --- |
| 1.20e | 完整经典客户端和 World Editor | 最低兼容边界、原版数据基线、旧地图格式和旧 JASS API 验证 |
| 1.31 | 完整 pre-Reforged 客户端和 World Editor | 前向兼容边界，以及较新经典客户端下的多人回归 |

所谓“完整”不是只保留压缩包或补丁程序：解压后的环境必须能够离线启动游戏、启动对应 World Editor、创建局域网地图，并包含《混乱之治》和《冰封王座》的经典数据及所需语言资源。

## 测试策略

用 `1.20e` 验证最低能力边界，用 `1.31` 验证旧格式地图的前向兼容。该方案不能逐版本证明 1.21-1.27，但能显著减少本地游戏副本；如果某张地图出现版本相关问题，再针对该问题临时引入中间版本，问题关闭后不长期保留。

## 原版底图所需数据

若最终需要从官方地图开始制作，应优先从 `1.20e` 完整安装中读取以下数据类别，并用 `1.31` 数据作差异对照：

- 《混乱之治》战役地图与本地化资源；
- 《冰封王座》战役地图与本地化资源；
- 基础及补丁 MPQ 中被地图引用的对象、脚本、模型、纹理、声音和字符串数据。

优先只提取工作所需的单关地图和必要依赖，不复制整个游戏目录到项目工作区。提取前记录安装来源、语言、版本号以及相关文件的 SHA-256。
